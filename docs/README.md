# Documentation

| Area | Purpose |
|---|---|
| `adr/` | Explicit architecture decisions |
| `roadmap/` | Current execution plan |
| `status/` | Verified state, blockers and audit evidence |
| `legacy/` | Historical source material |

A legacy file is project history, not automatically a current requirement. When sources conflict, record the conflict and resolve it with an ADR or approved canonical document.

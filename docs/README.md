# Documentation Map

## Canonical production documents

- `product/GAME_CANON.md` — what the game is.
- `architecture/TECHNICAL_ARCHITECTURE.md` — how 1.0 is built.
- `roadmap/MASTER_RELEASE_PLAN.md` — execution gates through release.
- `release/RELEASE_CRITERIA.md` — what “final” means.
- `production/ART_PIPELINE.md` — art/animation production rules.
- `status/CURRENT_STATE.md` — verified current state.
- `adr/` — decision history.

## Evidence and history

- `source/` — raw source material that informed the canon.
- `legacy/` — superseded/historical documents.

## Interpretation rule

Do not silently merge conflicting historical sources into implementation. Canonical documents represent the approved reconciliation. If a future decision changes the canon, record it through an ADR and update the affected canonical document.

# Source Material

This directory preserves source material used to derive canonical project documentation.

## RASTA_QUEST_RAW.md

The original uploaded `🎮 RASTA QUEST.md` is preserved byte-for-byte as `RASTA_QUEST_RAW.md`.

It is a large accumulated working/chat document containing repeated checkpoints, prompts, code examples, art-generation instructions and embedded base64 images. It is valuable evidence, but it is **not itself the canonical production specification** because later sections sometimes expand or conflict with earlier “locked” scopes.

Canonical decisions distilled from it live in:

- `../product/GAME_CANON.md`
- `../architecture/TECHNICAL_ARCHITECTURE.md`
- `../roadmap/MASTER_RELEASE_PLAN.md`
- `../production/ART_PIPELINE.md`

Do not edit the raw source merely to make it agree with the canon.

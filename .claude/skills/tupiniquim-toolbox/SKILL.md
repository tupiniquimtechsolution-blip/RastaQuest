# Tupiniquim Toolbox

Ative esta skill ao planejar, implementar, revisar, auditar ou melhorar este projeto.

## Roteamento
- UI/UX → UI UX Pro Max
- prompt engineering → Prompt Master
- pesquisa/web/social → Agent Reach
- pentest/remediação → Strix, somente alvos próprios/autorizados
- integração de software por CLI → CLI-Anything
- agentes/RAG → Awesome LLM Apps
- automação Instagram → OpenReply
- TTS local → Pocket TTS
- mídia generativa → Open Generative AI
- estudo de inferência local extrema → kimi-k3-in-c

## Método
1. Inspecione o repositório e confirme o estado real.
2. Consulte apenas as referências relevantes.
3. Não copie código externo cegamente; valide licença, dependências, risco e compatibilidade.
4. Preserve arquitetura e escopo.
5. Aplique a baseline de segurança descrita em `.claude/CLAUDE.md`.
6. Execute os checks disponíveis.
7. Registre achados em Issues verificáveis e priorizadas.
8. Entregue evidências, riscos e próximo passo.

Nunca exponha secrets e nunca realize teste ofensivo contra terceiros sem autorização explícita.

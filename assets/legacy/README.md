# Legacy Art & Asset Archive

Historical concept art, sprite experiments, processed variants and environment references are preserved here.

## Groups

- `characters/rasta/source/` — larger source exports
- `characters/rasta/processed/` — Photoroom/remove-background variants
- `characters/rasta/frames/` — small frame candidates
- `characters/rasta/concepts/` — action/reference sheets
- `environments/` — environment concepts
- `references/` — broad reference boards

Before final art production, define an art bible covering native resolution, palette, sprite scale, frame conventions, pivots, hitboxes/hurtboxes, export naming and provenance/licensing.

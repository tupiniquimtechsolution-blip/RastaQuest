## Promotion rule

A concept becomes a production/shipping asset only after:

1. identity review;
2. manual cleanup/consistency pass;
3. animation or tile validation;
4. mobile readability test;
5. provenance/license record;
6. cultural review where applicable;
7. explicit promotion into `game/assets/`.
